# 🇺🇸 American Dream

**A bold, modern American-style personal website**

Built for Amirhossein Bakhshi — 16-year-old Full-Stack Developer from Iran with one clear destination: the United States of America.

---

## Stack

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**

---

## Design Philosophy

Clean. Sharp. Confident.  
Inspired by the aesthetic of Silicon Valley companies — Linear, Vercel, Stripe, Apple.

- Almost pure black background
- High-contrast typography
- Minimal color (red accent for USA)
- Strong hierarchy
- English-first

---

## Run locally

```bash
git clone https://github.com/Amirhosseinbakhshi2011/american-dream.git
cd american-dream
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
